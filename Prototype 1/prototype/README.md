# SIROSIU local prototype

This isolated prototype lives separately from the root website. Its app is organized into `frontend/` and `backend/`; only the frontend is active today because the portfolio is a static site and currently has no server-side features.

## Run locally

1. Open a terminal in `prototype/`.
2. Run `npm install` if dependencies are not installed.
3. Run `npm run dev` and open the local URL printed by Vite.
4. Run `npm run build` for TypeScript and production-build validation.

Do not deploy or merge this prototype into the production site without a separate review and explicit authorization.
