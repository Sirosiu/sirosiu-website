# SIROSIU Website — Prototype 2

This is the isolated workspace for a fresh SIROSIU website redesign. The goal is a memorable, immersive experience that still communicates authentic work clearly and remains responsive, accessible, fast, and maintainable.

## Workspace map

- `site-next/` — clean home for the future replacement application. It is a planning scaffold and is not runnable yet.
- `docs/` — project brief, creative and technical direction, content, references, assets, decisions, roadmap, QA, and chat handoffs.
- `docs/archive/pre-reset-2026-10-24/` — copies of the notes that described the previous project direction. Historical only.
- Existing app copies in this folder — preserved while the fresh build is planned; not the new app's source of truth.

## Current state

Only the project-control layer and asset directory scaffold are being established now. No new website code, packages, or deployment changes are part of this phase. Read `PROJECT_STATE.md` and `AGENTS.md` before continuing.

The old applications are intentionally left where they are. The future application will be developed independently in `site-next/`; its framework configuration and source files will be added when implementation begins.
