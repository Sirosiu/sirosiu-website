# Content Inventory

Do not treat copied application text or earlier project notes as approved public copy. Confirm each fact with the user or an authoritative source before publication.

| Content | Status | Needed to verify |
|---|---|---|
| Name and positioning | Needs confirmation | Preferred display name, current focus, concise description |
| Biography | Needs confirmation | User-approved facts and tone |
| Projects | Needs review | Status, contribution, technologies, outcomes, screenshots, public links |
| Skills/capabilities | Needs review | Evidence from real work or learning |
| Experience/milestones | Needs review | Accurate dates and completed/ongoing/planned labels |
| Contact/social links | Needs confirmation | Approved public email and profile URLs |
| Images and media | Needs review | Source/ownership, permission, quality, intended use |
| Résumé | Optional | Current version and permission to publish |

Record evidence or approval beside each verified item. Missing information remains marked unknown.
