# Project Brief — SIROSIU Website

## Purpose

Create a distinctive, polished personal website that makes visitors want to explore and gives them a clear, evidence-based understanding of SIROSIU's work. Balance four goals: recognizable visual identity, purposeful immersive interaction, professional credibility, and engineering quality.

## Audiences

Recruiters, collaborators, and potential clients. The exact priority and messaging for each audience remain open.

## Experience goals

- Make identity and purpose easy to understand.
- Present genuine projects with visible technical evidence and accurate status.
- Give visitors a clear path to learn more and make contact.
- Use distinctive visuals and interaction to reward exploration without hiding essential information.
- Work well on mobile and desktop, with keyboard access and reduced-motion support.

## Success measures

Before implementation, define measurable content, accessibility, responsive, and performance acceptance checks. The experience should pass those checks and the user should approve it before any release proposal. Numerical performance budgets are intentionally unassigned until a representative prototype can be measured.

## Constraints

- Fresh visual direction. Prototype 1 is not the specification.
- No fabricated projects, metrics, qualifications, skills, or personal details.
- A static/readable fallback must remain useful if WebGL is unavailable or disabled.
- No backend or production migration without a demonstrated need and separate authorization.
- Reference code and third-party assets require source/license review before reuse.
