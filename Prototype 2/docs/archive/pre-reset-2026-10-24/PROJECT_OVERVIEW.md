# SIROSIU — Project Overview

SIROSIU is a personal project exploring engineering, technology, visual design, and creative experimentation through a web experience.

## Direction

The website is being developed around **Structured Surrealism**: a distinctive visual environment paired with clear navigation, readable content, and authentic project evidence. Immersive effects should support the content rather than obscure it.

## Technology

The current isolated prototype uses:

- React
- TypeScript
- Vite
- CSS-first visual effects
- Selective 3D technologies where justified by the prototype

The repository root and `prototype/` have separate responsibilities. Check the root README and prototype README for the current local development instructions.

## Project status

The website is a work in progress. Not every planned experience or interaction is complete, and proposed directions should not be treated as shipped features. Production hosting and deployment are managed separately from prototype development.

## Principles

- Describe implementation and project status honestly.
- Keep the experience responsive, accessible, and respectful of reduced-motion preferences.
- Prefer performance-conscious effects over decoration without purpose.
- Do not publish credentials, private configuration, internal planning records, or personal information that is not intended for public release.
