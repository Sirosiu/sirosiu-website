# SIROSIU isolated Stage 05 prototype

CSS-first React + TypeScript + Vite prototype. It does not change root website files or root dependencies.

## Run locally
1. Copy this entire `prototype/` directory into the root of the existing repository.
2. Open a terminal in `prototype/`.
3. Run `npm install` (installs only this prototype's dependencies).
4. Run `npm run dev`, then open the local URL printed by Vite.
5. Run `npm run build` to check the TypeScript and production build.

No WebGL, Three.js, or animation library is used. Navigation is keyboard operable, has a skip link and visible focus, and includes a reduced-motion CSS alternative. Unknown projects, biography, skills, journey details and contact links are explicitly marked as placeholders. Do not deploy.
